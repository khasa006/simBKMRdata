# Support and maintenance

- **Questions, bugs, and feature requests:** [GitHub Issues](https://github.com/khasa006/simBKMRdata/issues)
- **Maintainer:** See the current `Maintainer` field in `DESCRIPTION`.
- **Reproducible reports:** Provide `sessionInfo()`, minimal test data, and the exact function call.
- **Scientific interpretation:** Distinguish latent Gaussian correlation from transformed Gamma correlation. The PIP threshold is empirical and does not guarantee formal Type I error control.
- **Security or privacy:** Do not post confidential data or credentials in public issues. Contact the package maintainer using the address in `DESCRIPTION` for a private report.

Development follows the package's public issue and pull-request history. Maintenance and release schedules depend on contributor availability; no service-level commitment is made.
